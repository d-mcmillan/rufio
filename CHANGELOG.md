# Changelog

All notable changes to Rufio are documented per release. The format is loosely based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Current releases

- [**v1.0.6.3**](./docs/v1.0.6.3-release-notes.md) — TUI display fixes when the daemon is offline; sparkline wired to real substrate event rate; heartbeat-based daemon detection.
- [**v1.0.6.2**](./docs/v1.0.6.2-release-notes.md) — Install + first-run polish; `recall --types=goal` now functional; primer corrections; install snippets pinned correctly.

## Historical releases

Release notes for v1.0.0 through v1.0.6.1 are archived under [`docs/release-history/`](./docs/release-history/). v1.0.6.2 is the first publicly published release.
