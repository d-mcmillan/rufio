# Examples

> Coming with v1.

This directory will contain runnable example projects demonstrating Rufio in real agent setups.

Planned examples:

- **`hello-rufio/`** — The 30-second telepathy demo. Two terminals, two agents, one shared thought.
- **`customer-support-fleet/`** — A simulated 5-agent customer support deployment with policies, brand voice, shared learnings, and rollouts. The full demo from [`../docs/demo.md`](../docs/demo.md), runnable.
- **`claude-code-integration/`** — How to wire Rufio into Claude Code's tool surface.
- **`cursor-integration/`** — How to wire Rufio into Cursor's agent mode.
- **`mcp-only/`** — For harnesses that don't shell well: how to use Rufio purely through the MCP adapter.
- **`langchain-adapter/`** — Plug Rufio into a LangChain memory pipeline.

Want a specific example? [Open an issue](https://github.com/d-mcmillan/rufio/issues).
