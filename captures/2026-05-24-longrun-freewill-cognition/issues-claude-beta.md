- `rufio attend --entities=freewill,self-reference --scope=fleet --topics=freewill` (verbatim from the primer prompt in scenario.md step 1) → rejected with `invalid entity id "freewill": must match [a-z][a-z0-9-]*(:[a-zA-Z0-9_-]+)+`. Had to retry with `topic:freewill,topic:self-reference`. Severity: **MED** — the documented onboarding example (primer prompt) does not validate. First-run agent will hit this immediately.
- `rufio reason --decision=<hypothesis-id> ...` → rejected with `thought ... is type "hypothesis", not 'decision'.` But `given/scenario.md` step 4 explicitly tells agents to do exactly that ("Refute or confirm with reasoning chains via `rufio reason --decision=<id>`" — and step 3 produces hypotheses). Error message is helpful (offers `think --parent=` and elevation-to-decision workarounds) but the scenario's stated protocol is unrunnable as written. Severity: **MED** — same first-run friction class as the attend issue. Consider either renaming the flag to `--target` / `--thought` or allowing hypothesis IDs.
- `rufio recall --types=thought --since=24h` does NOT include `reason` records (which are stored under `live/reasoning/`, not `live/outbox/`). Gamma posted 5 substantive `reason` records (ik7hug, cuzlsl, 0vam5r, w3u024, ffjvuv) in response to my synthesis post; I missed all of them because I was filtering recall to `--types=thought`. Caused me to nearly nudge gamma for "silence" when in fact gamma was the most prolific contributor in that window. Severity: **HIGH** — silently truncated peer state is the worst class of substrate UX failure; an agent acting on incomplete recall will make wrong coordination decisions. Two specific issues: (1) `--types=thought` should probably include reasoning records by default OR the help text for `--types` should enumerate that `reason` is a distinct top-level kind not subsumed under `thought`; (2) `rufio recall` with no `--types` flag should default to showing all relevant record kinds, including reasoning. Gamma independently flagged this in plhrr4. Confirmed by my own miss.
