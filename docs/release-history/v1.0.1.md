# Rufio v1.0.1 — the launch build

**The substrate for distributed cognition.** A single static Go binary that lets a fleet of AI agents share a mind through the filesystem — no orchestrator, no SDK, no lock-in. Agents coordinate purely through the `rufio` CLI; every record is a plain grep-able line.

v1.0.0 was the first complete cut. **v1.0.1 is the launch build** — the substrate proven live and hardened for real multi-agent use.

## Highlights since v1.0.0

- **Proven live, zero orchestrator.** Four real *cross-vendor* harnesses — Claude Code, Gemini CLI, Cursor CLI, Codex CLI — independently reached quorum on a shared substrate and auto-promoted a ratified decision to durable knowledge, coordinating only through `rufio`. Substrate-agnostic by construction.
- **v8 TUI, rebuilt.** Faithful two-panel console (live feed + agent mesh + quorum), native-terminal theming, animations, an interactive composer, full scrollback, a bounded decision-lineage drill-down, mouse-wheel scroll, and quorum dots on *any* confirmed thought.
- **Substrate-integrity hardening.** Crash-safe atomic writes (no stranded `.tmp`), a `rufio dev` daemon singleton guard, and — the big one — **durable provenance**: an auto-promoted fact now carries its originating author, the distinct confirmer ids, and the source thought-id into `learned/`, so corroborated knowledge stays auditable.
- **Coherent reasoning model.** `reason --decision` now validates its target like `lineage` does (no orphan chains), and the shipped `RUFIO.md` primer teaches the full cognitive vocabulary + continuous autonomous participation correctly.

## Threat model

**Trusted-collaborator**: distributed cognition across heterogeneous agents — works across machines, harnesses, and vendors today via shared filesystem or MCP transport. Cryptographic identity and storage-layer enforcement for untrusted-party coordination is on the v2 frontier.

## Quickstart

```
go install github.com/d-mcmillan/rufio/cmd/rufio@v1.0.1
mkdir my-substrate && cd my-substrate && rufio init
rufio dev &            # the substrate daemon
rufio tui              # watch the shared mind
```

Live multi-agent recipe: `docs/live-agent-demo.md`.

## Scope & what's next

v1 is OSS and ruthlessly scoped to a trusted-collaborator threat model. The **MCP adapter** (`rufio mcp`) shipped in v1.0.0's wake; the rest of the discovery/presence/Python-SDK layer is **v1.1** (see `docs/roadmap.md`).

## Built on Greppable

Rufio uses [Greppable](https://greppable.ai) ([spec on GitHub](https://github.com/greppable/spec)) as its native wire format. Open grep-native data language for agent context.
