# Rufio v1.0.0 — Release Notes

**The substrate for distributed cognition.** v1.0 is the first complete release: 27 cognitive primitives, 5 daemon engines, a Bubble Tea v8 TUI, and a scripted launch demo. Single static Go binary.

---

## TL;DR

```bash
go install github.com/d-mcmillan/rufio/cmd/rufio@v1.0.0
mkdir my-substrate && cd my-substrate
rufio init demo
rufio demo --reset
# Watch two agents coordinate on customer:5821 in the TUI.
```

A single 6.7MB binary brings every primitive your agents need to share thoughts, observations, decisions, and goals across processes, harnesses, and machines.

---

## What this release does

Two agents — Claude Code and Cursor, or any pair of file-native harnesses — can now:

1. **Share thoughts and observations via memory** without any orchestrator. (`rufio observe`, `rufio recall`)
2. **Subscribe to live thought streams** the moment another agent writes one. (`rufio listen`, `rufio stream`)
3. **Crowd-confirm hypotheses into durable observations** automatically when 3+ peers confirm. (`rufio confirm`, `rufio refute`, `AutoPromoteHandler` engine)
4. **Hygiene memory with TTL** — short-lived hypotheses expire to `live/expired/` automatically. (`TTLSweeper` engine)
5. **Open private channels** for direct cognition. (`rufio summon`, `accept`, `decline`, `say`, `leave`, `close`)
6. **Self-coordinate on overlapping goals** — the substrate detects entity-id intersection and notifies both agents. (`rufio goal`, `goals list`, `goal complete`, `goal abandon`, `GoalOverlapHandler` engine)
7. **Audit any decision to the line** with reasoning chains + pinned context bundles. (`rufio think --type=decision`, `rufio reason --decision=<id>`, `rufio lineage <id>`)
8. **Reconstruct past substrate state** at any timestamp. (`rufio recall --as-of=<ts>`)
9. **Inspect everything** via columnar CLI output, JSONL streams, or the v8 Bubble Tea TUI.

## Daemon (`rufio dev`) — 5 engines

All five engines per the v1 architecture are operational:

- **RoutingHandler** — routes thoughts (outbox → matching inboxes via attention scan), summons (pending → explicit target inbox), and channel messages (active channel → other current members).
- **RetractPropagator** — on `live/retracted/<id>.gdl` create, appends `@retract` to every matching inbox copy.
- **AutoPromoteHandler** — when a hypothesis crosses the threshold (≥3 distinct `by:` authors AND `confidence ≥ 0.85`), writes an `@observation` to `learned/<subject-path>/<obs-id>.gdlm` plus an `@auto-promote` audit. Retraction-aware (writes `@promote-skipped` instead when the thought is retracted).
- **TTLSweeper** — periodic 10s ticker; moves expired thoughts to `live/expired/<agent>/`, expired pending summons to `live/summons/expired/`. Atomic via `os.Link + os.Remove` for TOCTOU safety.
- **GoalOverlapHandler** — on `live/goals/active/<id>.gdl` create, scans every other agent's active goals for entity-id intersection; writes `@goal-overlap` to both inboxes when non-empty.

Catch-up scan at daemon startup processes any unhandled records that landed while the daemon was down. SIGINT/SIGTERM trigger clean shutdown.

## Bubble Tea v8 TUI (`rufio tui`)

Four tabs: **fleet · channels · goals · lineage**. Live filesystem watching via fsnotify. v8 palette with full color profile ladder (truecolor → 256 → basic → NO_COLOR).

Keymap: `q` quit · `tab` cycle view · `←→`/`hl` navigate · `↑↓`/`jk` scroll · `enter` focus · `r` reveal raw `.gdl` · `?` help · `/` search · `esc` cancel.

Search overlay, reveal-raw modal, daemon-online indicator, empty-state hints, narrow-terminal vertical fallback. Teatest golden snapshots lock the visual fidelity.

**Read-only in v1.** Compose actions (write paths in the TUI) deferred to v1.1.

## Launch demo (`rufio demo`)

Scaffolds two agent identities (`claude-code` + `cursor`) via `swarm spawn`, starts daemon + listen subprocesses, runs scripted Beat-2 narration (cursor attends → claude-code thinks → routed), then launches the TUI. SIGINT cleanup with 5s SIGTERM grace then SIGKILL. Process-group ladder verified — zero zombies across repeated CI runs.

```bash
rufio demo --reset   # nukes live/ subtrees first; safe in a fresh project
```

## Architecture decisions worth knowing

- **Wire format is Greppable** (`.gdl`, `.gdlm`, `.gdlc`). Specs upstream at `greppable/spec`.
- **POSIX atomic writes everywhere** — `.tmp + os.Rename` for single-record writes; `os.Link + os.Remove` for TOCTOU-safe state transitions; `O_APPEND` for confirms (sub-PIPE_BUF atomicity).
- **No mocks for filesystem or process operations** in any test. Race-clean tests on macOS + Ubuntu CI build a real binary once and exec it against `t.TempDir()` workdirs.
- **Typed errors throughout** — every error implements `RufioError` (`Error() string` + `ExitCode() int`); `HandleError` is the single sink for the `rufio <cmd>:` prefix invariant.
- **Single static binary.** No runtime, no daemons-other-than-`rufio dev`, no orchestrator. The filesystem is the API.

## What's NOT in v1.0

- **`mcp` adapter** — the only deferred command. Non-shell harnesses (those without shell-out) will need this; landing in v1.1+.
- **TUI compose actions** — write paths from the TUI (e.g., starting a summon from the fleet pane). Read-only in v1.
- **Cross-process daemon singleton enforcement** — `.rufio/locks/dev.pid` is written but not lock-enforced; two concurrent `rufio dev` instances overwrite the pid file silently. A liveness check + reclaim is planned for v1.1.
- **Async TUI startup walk**, **closed-channels view**, **500ms fade-in motion** — all deferred to v1.1 polish.
- **Counterfactual lineage**, **trust networks**, **federation** — v1.2+ research scope.

## Threat model

**Trusted-collaborator**: built for cooperatively-coordinating agent teams, not adversarial parties. Same posture as Postgres / Redis / git — trust your operators. Hardening for untrusted-party coordination (cryptographic identity, storage-layer privacy enforcement, multi-tenancy) is on the v2 frontier.
