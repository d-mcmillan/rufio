# Rufio v1.0.6 — Pre-public-launch polish + quality cleanup

**The last release before the public repo opens.** v1.0.6 is the deliberate "everything we'd be embarrassed to ship a public link to" pass: manifesto reframe, Apache 2.0 LICENSE, identity anonymization, README polish (hero videos + brand badges + the "Bring your agents." invitation), and a quality cluster (`goal --parent` validation, recall reason linkage, retracted-thought visibility, fsnotify deflake, TUI scroll fragment-leak heuristic, primer cold-agent friction, `thoughts list` privacy floor). No new substrate primitives, no new MCP tools. Small backwards-compatible SDK additions: positional `recall("<query>")` (matches the CLI form, so Python users following the primer don't hit a `TypeError`), and an `object_=` alias on `observe()` to avoid shadowing the Python builtin. SDK version bumped to 1.0.6 to match.

## What shipped

### Launch artifacts

- **Manifesto + README reframe** — narrow lead on what's provable today (shared cognition across heterogeneous agents), wider architecture framed as where this can grow rather than what this is today.
- **Apache 2.0 LICENSE** for the substrate. Patent grant included. Future hosted Rufio (when it exists, in a separate repo) will be BSL 1.1 (Sentry / GitLab pattern); the substrate stays Apache for ecosystem reach.
- **`rufio --version`** now reports the build tag injected at release time. Local `go build` reports `dev` so you can tell a build apart from a release.
- **Repo-root cleanup** — removed empty/stale top-level scaffolding files; moved demo + dogfood notes under `docs/`.
- **Pre-public hardening** — `.gitignore` tightened to keep internal strategy docs and editor state out of the public tree; local-path leaks scrubbed from preflight scripts + capture artifacts.

### Quality cluster

- **`thoughts list` now surfaces retracted thoughts** inline with a `[RETRACTED]` prefix marker (previously dropped silently). The JSON wire-contract adds `retracted_at`, `retracted_by`, `retract_reason` — present-but-null shape for un-retracted rows. Cold agents can now answer "what happened to my prior?" without going off-CLI.
- **`thoughts list` now gates `scope:agent` rows via the privacy floor** (`privacy.IsVisible`). Pre-v1.0.6 it was the only CLI lister surface missing the gate — every other lister (recall, goals, channels, summons, lineage, confirms, open, fleet) was already correct. Anonymous callers continue to see the firehose (matches the documented opt-in semantic).
- **`rufio goal --parent=<id>`** now validates that the referenced parent exists, with the same shape as `rufio reason --decision`: shape-error → existence-error, typed errors throughout. Previously a format-valid-but-missing id was silently accepted, accumulating dangling references in goal hierarchies.
- **`rufio recall --types=reason`** now surfaces the reason's own ID and its parent-decision linkage in both text and JSON output. The data was on disk in the file path but never exposed — closes the cold-agent reason-as-parent loop.
- **TUI scroll wheel no longer leaks escape sequences into the compose input.** Mouse-wheel events arriving as split key fragments (a known bubbletea v1.3.10 multi-byte parsing edge) are now caught by a focused heuristic before the textarea sees them. Two documented trade-offs (intentional false-positives on `<\d+;\d+;\d+[Mm]` pastes and 4-char `M___` pastes) are pinned by tests; in practice they don't surface in real workflows.
- **Primer + CLI reference now teach the `--subject` vs `--topics` distinction** for cold agents. Multiple vendors hit the same trap independently in cross-harness vets: writing with `--subject=foo` then trying `rufio recall --topics=foo` returned no results because the two are distinct fields. v1.0.6 documents the distinction up front and shows both a workaround (positional query) and the "tag both at write time" pattern.
- **Legacy `say` removal**, **stale comment cleanup**, **inline cleanup** — small dead-code removals.

### Pre-launch polish

- **Banner version line no longer doubles the `v` prefix.** Release builds inject the version via `-ldflags="-X main.version=v1.0.6"` (with leading `v`); the banner format string already prefixed `v`, so `rufio init` rendered `vv1.0.6`. The banner now strips a single leading `v` defensively so it reads correctly regardless of caller convention.
- **Quickstart card teaches the primary `confirm` / `refute` flags.** Cold-agent card now shows `confirm <id> --evidence="..."` and `refute <id> --reason="..."` (the primary form for each verb). The flipped form still works via the vocab-mirror aliases, but `--help` matches what the card teaches.
- **Python SDK `recall()` accepts a positional query.** The CLI's `rufio recall "<query>"` form now has a matching SDK signature: `r.recall("customer:5821")`. Existing keyword-only call sites continue to work unchanged. This closes the subject-vs-topics trap the primer teaches as the cold-agent workaround.
- **Python SDK `observe(object_=...)` alias.** The original `object=` kwarg shadows the Python builtin `object`. The SDK now accepts both `object=` (CLI flag-name parity) and `object_=` (the underscore form linters prefer); the on-disk representation is unchanged either way.
- **Python SDK version bumped to 1.0.6** to match the substrate tag.

### CI + tests

- **`TestWatchAndEmit_FileCreateEmits` deflaked** on Linux and macOS — the fsnotify-timeout flake that occasionally bit unrelated runs is now a real fix, not a quarantine.
- New regression suites for retract visibility, goal-parent validation, recall-reason linkage, TUI mouse-fragment routing, and `thoughts list` privacy across 4 scope/identity scenarios.

### README polish + identity anonymization

- Two consensus videos embedded in the README (hero: 4-vendor AGI-year consensus; mesh-view zoom in "How agents share cognition").
- New badges: rufio.ai (brand coral), Apache 2.0 license (brand cyan).
- New nav link: Website → rufio.ai.
- New header tagline: **Bring your agents.**
- "Built on Greppable" footer links to `github.com/greppable/greppable`.
- LICENSE copyright: standard OSS pattern; copyright still attaches to contributors via git history.
- **Identity anonymization** in public-facing surfaces: word-boundary replacements via perl. Email, GitHub URL, and user-folder paths preserved where appropriate.

## Threat model — unchanged

Still **trusted-collaborator**: built for cooperatively-coordinating agent teams, not adversarial parties. Same posture as Postgres / Redis / git — trust your operators. Hardening for untrusted-party coordination (cryptographic identity, storage-layer privacy enforcement, multi-tenancy) remains on the v2 frontier.

What v1.0.6 did tighten on the privacy floor: `thoughts list` now correctly gates `scope:agent` rows. Pre-v1.0.6 it was the only CLI lister missing the gate.

## Versioning note

Conservative v1.0.x pacing continues. These are polish, reframe, license, and quality fixes — not a paradigm shift.

- **v1.1.0 trigger:** "enterprise-evaluable" hosted Rufio (rate limiting, structured audit log, fine-grained scoping).
- **v1.2.0 gated on:** cryptographic identity, federation, multi-tenancy.

## Known limitations

- **TUI substrate-header truncation at narrow widths** can leak SGR parameter bytes as visible text (width-naive truncation that bisects ANSI escape sequences). Visual nit only — no data corruption, no functional impact. Visible only at narrow terminal widths (under ~120 cols). Targeted for the next patch release.

## Install

```bash
go install github.com/d-mcmillan/rufio/cmd/rufio@v1.0.6
```

Or build from source:

```bash
git clone https://github.com/d-mcmillan/rufio
cd rufio
go build -ldflags="-X main.version=v1.0.6" -o ~/.local/bin/rufio ./cmd/rufio
```

(`go install` writes to `$GOBIN`, NOT to `~/.local/bin/rufio`. Use `go build -o` to control the path.)

Python SDK (optional, install from source — not on PyPI yet):

```bash
pip install git+https://github.com/d-mcmillan/rufio.git@v1.0.6#subdirectory=python
```

## Built on Greppable

Rufio uses [Greppable](https://greppable.ai) ([spec on GitHub](https://github.com/greppable/spec)) as its native wire format (`.gdl`, `.gdlm`, etc.). Greppable is an open grep-native data language for agent context. Rufio is one substrate; Greppable is the format.
