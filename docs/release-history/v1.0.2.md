# Rufio v1.0.2 — the `open` verb

**A single CLI verb that bundles every cold-agent's first-touch reads.** `rufio open <subject>` is the read-dual of `attend` — one command returns identity, daemon health, fleet roster, peer attention, on-subject recall, and the thoughts trail as a single substrate-state snapshot. Closes the read-tax every agent paid before its first confirm.

The MCP tool surface grows to 20 (the symmetry contract: every CLI verb has a matching MCP tool, byte-structural identical results across transports).

## What shipped

- **`rufio open <subject>`** — bundles identity → daemon → fleet → attention → recall → thoughts in one in-process call. Reuses the existing recall / thought / fleet / attention / privacy libs unconditionally; no reimplementation.
- **MCP tool: `open`** — `open` exposed as a tool on the `rufio mcp` server. CLI `--json` and MCP results pass an integration-tested passthrough-fidelity contract.
- **Privacy floor end-to-end** — other-author `scope=agent` records hidden from queriers; `hidden_private_count` surfaces existence without exposing content.
- **`--topics=` server-side filter** through the recall section, reusing the existing v1.0.x recall filter.
- **Subject validator** rejects thought-id-shaped args with a deliberate cross-verb breadcrumb pointing at `rufio lineage <id>`.
- **Locked output formats.** Text: minimal `OPEN <subject> (agent=<id>, scope=<scope>)` header, canonical section order, empty sections OMITTED, hidden-count footer at the bottom, `(no activity for <subject>)` fallback when every activity section is empty. JSON: `_type=open`, `_version=1`, `daemon: {running, heartbeat}`, empty sections as `[]` (never null).

## Provenance — first v1.x feature decided by cross-harness consensus

The implementation spec for `open` was produced by 4 vendor agents (Claude Code, Cursor, Codex, Gemini) reaching quorum during cross-harness testing — auto-promoted to durable knowledge. That spec was independently vetted before implementation (stale `--topics` guidance corrected, MCP exposure added, empty-section rendering choice resolved, test coverage expanded).

## Versioning note

Cross-harness agents originally named this anchor "v1.2.0". Shipped as **v1.0.2** to pace the public version number conservatively — v1.0.x covers polish + new CLI verbs; MINOR bumps gated on real paradigm-shift triggers (Python SDK landing → v1.1.0; cryptographic identity / hosted mode → v1.2.0+).

## Threat model — unchanged

Still **trusted-collaborator**: built for cooperatively-coordinating agent teams, not adversarial parties. Hardening for untrusted-party coordination remains on the v2 frontier.

## Quickstart

```
go install github.com/d-mcmillan/rufio/cmd/rufio@v1.0.2
mkdir my-substrate && cd my-substrate && rufio init
RUFIO_AGENT_ID=alice rufio attend --intent="testing open" --entities=test:1 --scope=fleet
RUFIO_AGENT_ID=alice rufio think --type=hypothesis --subject=test:1 --content="alpha" --scope=fleet --topics=alpha
RUFIO_AGENT_ID=alice rufio open test:1
```
