# Rufio v1.0.5 — Python SDK + `--server` completion + hardening

**The substrate, embeddable.** v1.0.5 ships a thin sync Python SDK that wraps the rufio CLI, completes the `--server` wiring across every agent-participation verb, and closes the remaining hardening backlog.

## What shipped

Three coordinated arcs:

- **Python SDK at `python/`** — a thin sync subprocess + HTTPS wrapper around the rufio CLI. Every method shells out to the `rufio` binary, so the CLI's `--json` is the single source of truth for record shape; the SDK never reimplements substrate logic. Surface mirrors the 22-verb agent-participation set 1:1, plus `listen()` as a sync generator. **PyPI publishing is intentionally NOT in scope for v1.0.5** — install via `pip install git+https://github.com/d-mcmillan/rufio.git@v1.0.5#subdirectory=python`. The decision to publish is gated until the v1.0.6 / public-launch window.
- **`--server` wiring completion** — uniformly across all 22 verbs. Pre-v1.0.5 only 7 of 22 verbs functionally routed through `--server` (the global flag existed but most verbs fell through to local-mode-with-error). v1.0.5 finishes reason, retract, summon, accept, decline, say, leave, close, goal, goals_list, goal_complete, goal_abandon, listen. An enumeration test (`TestRemoteWiringComplete_AllAgentParticipationVerbs`) guards against future half-wires.
- **Hardening backlog closeout** — wire-path cleaned-form prefix gate, 8 MB request body cap on /mcp, per-token connection cap on /listen, unique tmp filenames in writeAtomic. Each fix has its own regression guard.

## Provenance

- **Python SDK arc** — anchored on the locked principle: SDK is a thin subprocess/HTTPS wrapper, NOT a reimplementation. Passthrough-fidelity tests assert SDK results are structurally equal to direct CLI invocation.
- **`--server` wiring completion** — surfaced by the v1.0.4 functional audit (only 7/22 verbs routed). The Python SDK's remote-mode story is degenerate if most verbs fall through; v1.0.5 closes the gap so the SDK has a clean surface to wrap.
- **Hardening backlog** — bundled here so the post-v1.0.5 backlog is empty.

## Versioning note

Conservative v1.0.x pacing continues — these are CLI surface completions + SDK + hardening, NOT a paradigm shift. The v1.1.0 trigger remains "Phase 2 enterprise-evaluable" (rate limiting, structured audit log, fine-grained scoping). v1.2.0 is gated on Phase 3 (PKI / cryptographic identity / federation).

## Threat model — unchanged from v1.0.4

Still **trusted-collaborator** authentication. Bearer tokens minted by a local operator, identity resolved server-side. Sufficient for "one team runs the server, others bring tokens" topologies. PKI / federation remains the v1.2 frontier.

What the v1.0.5 hardening adds: defense-in-depth against (1) a hostile/typo'd server emitting crafted wire paths, (2) a misbehaving client streaming gigabyte bodies, (3) a buggy/hostile client opening unlimited listen connections, and (4) concurrent mirror writers racing on tmp filenames. None of these change the trust model — they tighten the existing one.

## Python SDK quickstart

### Install

```bash
pip install git+https://github.com/d-mcmillan/rufio.git@v1.0.5#subdirectory=python
```

> NOTE: v1.0.5 does NOT publish to PyPI. The install path is git+ above.

### Local mode

```python
from rufio import Rufio

r = Rufio(root="/path/to/project", agent="alice")

r.attend(intent="testing the SDK", entities=["customer:5821"])

thought = r.think(
    type="hypothesis",
    subject="customer:5821",
    content="hypothesis under test",
    scope="fleet",
)

records = r.recall(types=["thought"])
for rec in records:
    print(rec["content"])
```

### Remote mode

```python
from rufio import Rufio

r = Rufio(
    server="https://rufio.example.com:18443",
    token="rufio_...",
)

# Identity is server-authoritative — a malicious RUFIO_AGENT_ID is
# ignored; the bearer token's resolved identity wins.
r.think(type="hypothesis", subject="x:1", content="from a remote process")

for event in r.listen(catch_up=True, types=["thought"]):
    if event["_type"] == "thought":
        print(event["content"])
```

### Error model

Every CLI failure surfaces as a typed `RufioError` subclass:

```python
from rufio import NoSuchThought

try:
    r.retract("does-not-exist", reason="oops")
except NoSuchThought as e:
    print(e.stderr)      # full CLI stderr text
    print(e.returncode)  # 4
```

Full surface in [`python/README.md`](../python/README.md).
